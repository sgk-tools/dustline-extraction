## MakeHuman graphical asset (CC0 1.0 Universal)

The anatomical head is cropped and aligned from the MakeHuman hm08 base mesh.
Source: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj
Primary license: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md

The base mesh explicitly carries a CC0 dedication in its own header. Section C of the primary license releases the bundled graphical assets under CC0. The MakeHuman application source is AGPL; no application source or algorithms were incorporated. Only the CC0 anatomical mesh was used. The original licence copy is MAKEHUMAN_LICENSE.md.

## Original surface atlas and labels

rig_albedo.jpg, rig_normal.jpg, rig_rough.jpg and sector_sign.png are generated by the project's own scripts. Skin shading is an original simple material, not a photographic skin scan. Sector sign glyphs were rasterized using the installed DejaVu font; no font file is distributed.
